# Обрій - програми

Готові збірки месенджера **Обрій** для Windows, Linux і Android.
Коду тут немає - лише файли для завантаження.

Завантажувати зручніше зі сторінки з інструкціями:
**https://obriy.luchezarikcentr.com/download**

| Система | Файл |
|---|---|
| Windows 10/11 | `Obriy-Setup.exe` |
| Linux (будь-який) | `Obriy.AppImage` |
| Ubuntu / Debian | `obriy_amd64.deb` |
| Android | `Obriy.apk` |

Програма відкриває той самий Обрій, що й у браузері (той самий акаунт і шифрування).
Реєстрація - за запрошенням власника.
